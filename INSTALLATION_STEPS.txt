PROBLEM: Page shows blank screen
SOLUTION:
  - Check Apache error log
  - Verify PHP syntax: php -l index.php
  - Check file permissions

PROBLEM: 404 on API calls
SOLUTION:
  - Verify files exist in api/ folder
  - Check file permissions (should be 644)
  - Restart Apache: /etc/init.d/apache2 restart

PROBLEM: Empty dropdowns
SOLUTION:
  - Check browser console (F12) for JavaScript errors
  - Test API directly: curl http://localhost/hyundai-parts/api/get_models.php
  - Verify database connection in config/db.php

PROBLEM: Engine oil still missing
SOLUTION:
  - Check database data:
    mysql -u hyundai_user -p -e "
      USE hyundai_parts;
      SELECT * FROM genuine_parts 
      WHERE product_name LIKE '%엔진오일%';
    "
  - Verify compatible_engines column has '전체' value

PROBLEM: Database connection failed
SOLUTION:
  - Check config/db.php credentials
  - Verify MariaDB is running
  - Test connection: mysql -u hyundai_user -p
