주요 파일 설명

[사용자 인터페이스]

[설정]
- config/db.php          : DB 연결 (PDO)
                          보안 함수
                          에러 처리

[엑셀 처리]
- import_excel_data.php  : 독립 실행 스크립트
- admin/api/import_excel.php : API 버전

데이터베이스 구조

car_models
  ├── id (PK)
  ├── manufacturer (제조사)
  ├── category (카테고리)
  ├── brand_name (브랜드명)
  ├── model_name (모델명)
  ├── generation (세대)
  └── created_at

car_engines
  ├── id (PK)
  ├── car_model_id (FK → car_models)
  ├── engine_type (엔진 타입)
  └── engine_name (엔진명)

genuine_parts
  ├── id (PK)
  ├── category_main (대분류)
  ├── category_sub (소분류)
  ├── product_name (제품명)
  ├── capacity (용량)
  ├── part_number (부품번호, UNIQUE)
  ├── compatible_engines (호환 엔진)
  ├── notes (비고)
  └── created_at
