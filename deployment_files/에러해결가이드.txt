====================================================
  🔧 "부품 검색 중 오류가 발생했습니다" 에러 해결
====================================================

📸 증상:
검색 페이지에서 "59.19.231.47 내용: 부품 검색 중 오류가 발생했습니다."
라는 메시지가 표시됨

====================================================
🎯 원인 및 해결 방법
====================================================

이 에러는 주로 다음 3가지 원인으로 발생합니다:

----------------------------------------------------
원인 1: config/db.php 파일이 업로드되지 않음 ⭐ 가장 흔함
----------------------------------------------------
증상:
- 데이터베이스 연결 실패
- 모든 페이지에서 에러 발생

해결 방법:
1. FTP/SFTP로 접속
2. deployment_files/db.php 파일을 확인
3. 다음 경로에 업로드:
   /volume1/web/hyundai-parts/config/db.php
4. ⚠️ 중요: 기존 파일을 덮어쓰기!

확인 방법:
SSH 접속 후:
  cat /volume1/web/hyundai-parts/config/db.php

다음 내용이 있어야 합니다:
  define('DB_PASS', 'Kdmdtt1225**');

----------------------------------------------------
원인 2: 데이터베이스 비밀번호가 틀림
----------------------------------------------------
증상:
- PDO 연결 에러
- "Access denied for user" 에러

해결 방법:
1. SSH로 서버 접속
2. MariaDB 실제 비밀번호 확인
3. config/db.php 파일 수정:
   
   vi /volume1/web/hyundai-parts/config/db.php
   
   11번째 줄 확인:
   define('DB_PASS', 'Kdmdtt1225**');
   
   실제 비밀번호로 변경 후 저장

4. 다른 PHP 파일들도 동일하게 수정:
   - add_notes_column.php (7번째 줄)
   - admin_vehicle_parts.php (67번째 줄)
   - save_vehicle_parts_api.php (7번째 줄)
   - get_vehicle_parts_api.php (7번째 줄)
   - api/search_debug.php (14번째 줄)
   - api/vehicle_models_api.php (7번째 줄)
   - api/vehicle_engines_api.php (7번째 줄)

----------------------------------------------------
원인 3: vehicle_parts_mapping 테이블에 데이터 없음
----------------------------------------------------
증상:
- 검색 결과가 비어있음
- "부품을 찾을 수 없습니다" 메시지

해결 방법:
1. 관리자 페이지 접속:
   http://59.19.231.47/hyundai-parts/admin_vehicle_parts.php

2. 로그인: admin / admin123

3. 차량 선택 후 부품 추가:
   - 차명 선택 (예: G80)
   - 세대 선택
   - 연료 선택
   - 엔진 선택
   - 부품 추가 버튼 클릭

4. 최소 1개 이상의 부품을 추가해야 검색 가능

====================================================
🔍 진단 도구 사용
====================================================

원인을 정확히 파악하기 위해 진단 도구를 사용하세요:

1. test_db_connection.php 업로드
   deployment_files/test_db_connection.php 
   → /volume1/web/hyundai-parts/test_db_connection.php

2. 웹 브라우저로 접속:
   http://59.19.231.47/hyundai-parts/test_db_connection.php

3. 진단 결과 확인:
   ✅ 성공: 녹색 박스
   ❌ 실패: 빨간색 박스
   ℹ️ 정보: 파란색 박스

4. 문제 항목을 위의 해결 방법대로 수정

====================================================
📋 체크리스트 (순서대로 확인)
====================================================

□ 1단계: config/db.php 파일 확인
   → 파일 존재 여부
   → DB_PASS 값 확인

□ 2단계: 테이블 존재 확인
   → car_models
   → car_engines
   → genuine_parts
   → vehicle_parts_mapping

□ 3단계: 데이터 확인
   → vehicle_parts_mapping에 데이터 1개 이상

□ 4단계: notes 컬럼 확인
   → add_notes_column.php 실행했는지

====================================================
🚀 빠른 해결 방법
====================================================

대부분의 경우 다음 순서로 해결됩니다:

1️⃣ config/db.php 파일 업로드
   FTP로 deployment_files/db.php를
   /volume1/web/hyundai-parts/config/db.php에 업로드

2️⃣ 브라우저 캐시 삭제
   Ctrl + Shift + Delete (또는 Cmd + Shift + Delete)

3️⃣ 페이지 새로고침
   Ctrl + F5 (강력 새로고침)

4️⃣ 여전히 에러 발생 시
   test_db_connection.php로 진단

====================================================
💡 자주 발생하는 실수
====================================================

❌ 실수 1: db.php를 루트에 업로드
   올바른 경로: /volume1/web/hyundai-parts/config/db.php
   잘못된 경로: /volume1/web/hyundai-parts/db.php

❌ 실수 2: 파일 덮어쓰기 안 함
   기존 config/db.php가 있어도 새 파일로 덮어써야 합니다.

❌ 실수 3: 비밀번호에 특수문자 오타
   Kdmdtt1225** (별표 2개!)
   복사-붙여넣기 권장

❌ 실수 4: 마이그레이션 미실행
   add_notes_column.php를 실행해야 notes 컬럼이 생성됩니다.

====================================================
🆘 여전히 해결 안 될 때
====================================================

1. test_db_connection.php 결과 스크린샷 촬영

2. 다음 정보 수집:
   - 에러 메시지 전체
   - 발생 URL
   - 수행한 작업 내역

3. 개발자 콘솔 확인 (F12):
   - Network 탭에서 API 응답 확인
   - Console 탭에서 JavaScript 에러 확인

4. 개발자에게 연락 시 위 정보 전달
