====================================================
Git 없이 배포하기
====================================================

이 파일들은 Git 없이 FTP/SFTP로 직접 업로드하도록
준비되었습니다.

Git을 나중에 설치하려면:
1. Synology 패키지 센터에서 "Git Server" 설치
2. SSH 접속 후: sudo apt-get install git (일부 모델)
