----------------------------------------------------

----------------------------------------------------
1) 접속: http://59.19.231.47/hyundai-parts/admin_vehicle_parts.php

3) 차량 선택 (예: G80)

5. 주요 기능
====================================================

✅ 비고(Notes) 필드
   - 관리자가 부품 매핑 시 상세 정보 입력 가능
   - 연식, 특이사항, 적용 조건 등 기록
   - 검색 결과에 자동으로 표시

✅ 프로덕션 DB 설정
   - 모든 파일에 올바른 DB 비밀번호 적용
   - 500 에러 해결

✅ 안전한 마이그레이션
   - 컬럼 중복 추가 방지
   - 여러 번 실행해도 안전

====================================================
6. 문제 해결
====================================================

Q1: 마이그레이션 실행 시 에러가 발생합니다.
A1: DB 비밀번호가 정확한지 확인:
    - 비밀번호: Kdmdtt1225**
    - MariaDB 사용자: root
    - 데이터베이스: hyundai_parts

Q2: 비고 입력란이 보이지 않습니다.
A2: 브라우저 캐시를 삭제하고 새로고침 (Ctrl+F5)

Q3: 저장은 되는데 비고가 표시되지 않습니다.
A3: 마이그레이션을 실행했는지 확인
    http://59.19.231.47/hyundai-parts/add_notes_column.php

Q4: 500 에러가 발생합니다.
A4: 다음을 확인:
    1) 파일이 올바른 경로에 업로드되었는지
    2) DB 비밀번호가 정확한지 (Kdmdtt1225**)
    3) 파일 권한 확인 (644 또는 755)

7. 롤백 방법 (문제 발생 시)
====================================================

만약 문제가 발생하면 백업된 파일로 복원:

1) 백업 파일 위치 확인
2) 변경된 파일들을 백업 파일로 교체

      삭제하려면 다음 SQL 실행:
