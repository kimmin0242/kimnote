📊 CSV 데이터 관리 시스템

현대차 부품 검색 시스템 - CSV 관리 기능 배포 패키지

📦 패키지 내용

  • export_parts_csv.php - CSV 내보내기 기능
  • import_parts_csv.php - CSV 가져오기 및 검증
  • admin_index.php - 업데이트된 관리자 페이지
  • DEPLOY.sh - 자동 배포 스크립트
  • README.md - 상세 사용 가이드
  • MANUAL_DEPLOY.md - 수동 배포 가이드

⬇️ 다운로드

배포 패키지를 다운로드하여 서버에 배포하세요.

📥 csv_deployment.tar.gz 다운로드 (12 KB)

1 wget으로 다운로드

Synology NAS SSH에 접속한 후:

# 임시 디렉토리로 이동 cd /tmp # wget으로 배포 패키지 다운로드 wget http://59.19.231.47/hyundai-parts/csv_deployment.tar.gz # 압축 해제 tar -xzf csv_deployment.tar.gz # 배포 디렉토리로 이동 cd csv_deployment

2 자동 배포 실행

배포 스크립트를 실행하여 자동으로 설치:

# 실행 권한 부여 chmod +x DEPLOY.sh # 배포 스크립트 실행 ./DEPLOY.sh
⚠️ 주의: 배포 스크립트는 기존 파일을 자동으로 백업한 후 새 파일로 교체합니다.

3 수동 배포 (선택사항)

자동 스크립트를 사용하지 않는 경우:

# CSV 파일 복사 cp export_parts_csv.php /volume1/web/hyundai-parts/ cp import_parts_csv.php /volume1/web/hyundai-parts/ # 관리자 페이지 백업 cp /volume1/web/hyundai-parts/admin/index.php \ /volume1/web/hyundai-parts/admin/index.php.backup # 새 관리자 페이지 복사 cp admin_index.php /volume1/web/hyundai-parts/admin/index.php # 권한 설정 chmod 644 /volume1/web/hyundai-parts/*.php chmod 644 /volume1/web/hyundai-parts/admin/index.php

4 배포 확인

웹 브라우저에서 관리자 페이지 접속:

URL: http://59.19.231.47/hyundai-parts/admin/ ID: admin PW: admin123

확인 사항:

  • "CSV 데이터 관리" 섹션이 보임
  • "CSV 다운로드" 버튼 클릭 가능
  • "CSV 업로드" 폼 작동

✨ 새로운 기능

  • 모든 차량-부품 매핑 데이터를 Excel로 내보내기
  • Excel에서 편집 후 CSV 업로드로 일괄 업데이트
  • 자동 데이터 검증 및 오류 보고
  • 누락된 차량/엔진/부품 자동 생성
  • 트랜잭션 기반 안전한 데이터 업로드
