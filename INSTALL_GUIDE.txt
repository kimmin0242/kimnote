업데이트 가이드
===============================================

===============================================
1. 수정 내용
===============================================

✅ 연료형식/엔진형식별 부품 필터링 개선
   - 가솔린/디젤/LPG별 다른 엔진오일 표시
   - 엔진형식별 다른 오일량 표시
   - 엔진형식별 다른 필터 표시

✅ 카테고리 분류 정확도 향상
   - 엔진류: 엔진오일(대/소), 오일필터, 오일량
   - 필터류: 에어필터, 에어컨필터 (오일필터 제외)
   - 기타: 미션오일, ATF, 부동액 등

===============================================
2. 파일 업로드 방법
===============================================

방법 1: 개별 파일 교체
----------------------
1. index.php.new 파일을 다운로드
2. Synology File Station에서 /volume1/web/hyundai-parts/ 폴더 열기
3. 기존 index.php를 index.php.backup으로 백업
4. index.php.new를 index.php로 이름 변경하여 업로드

5. search_parts_advanced.php.new 파일을 다운로드
6. /volume1/web/hyundai-parts/api/ 폴더 열기
7. 기존 search_parts_advanced.php를 백업
8. search_parts_advanced.php.new를 search_parts_advanced.php로 업로드

방법 2: 압축 파일 사용
----------------------
1. hyundai-parts-engine-filter-fix.tar.gz 다운로드
2. Synology SSH 접속:
   cd /volume1/web/hyundai-parts
   
3. 기존 파일 백업:
   cp index.php index.php.backup
   cp api/search_parts_advanced.php api/search_parts_advanced.php.backup
   
4. 업로드한 압축 파일 압축 해제:
   tar -xzf hyundai-parts-engine-filter-fix.tar.gz
   
5. 파일 권한 확인:
   chmod 644 index.php
   chmod 644 api/search_parts_advanced.php

===============================================
3. 테스트 방법
===============================================

테스트 1: G80 RG3 전체 검색
---------------------------
1. 차명: G80
2. 세대: RG3
3. 연료형식: (전체)
4. 검색 클릭

예상 결과:
- 엔진류 탭에 모든 엔진형식의 부품 표시
- 가솔린/디젤/LPG별 다른 엔진오일 표시

테스트 2: G80 RG3 가솔린만
---------------------------
1. 차명: G80
2. 세대: RG3
3. 연료형식: 가솔린
4. 검색 클릭

예상 결과:
- 엔진류 탭에 가솔린 엔진 부품만 표시
- 디젤/LPG 부품은 표시 안 됨

테스트 3: 카테고리 분류 확인
---------------------------
검색 후 각 탭 확인:
- 엔진류: 엔진오일, 오일필터만
- 필터류: 에어필터, 에어컨필터만
- 기타: 미션오일, 부동액, ATF 등

===============================================
4. 문제 해결
===============================================

문제: "검색 중 오류가 발생했습니다"
해결: 
1. 파일 경로 확인: api/search_parts_advanced.php 존재 여부
2. 파일 권한 확인: chmod 644
3. DB 연결 확인: config/db.php 설정

문제: 부품이 너무 많이 표시됨
해결:
1. 브라우저 캐시 삭제 (Ctrl+Shift+Delete)
2. 페이지 새로고침 (Ctrl+F5)

문제: 카테고리 분류가 이상함
해결:
1. index.php 파일이 올바르게 업로드되었는지 확인
2. JavaScript 콘솔 에러 확인 (F12)

===============================================
